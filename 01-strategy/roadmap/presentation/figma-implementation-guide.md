## Design System Reference

### Color Palette
- **Primary Blue/Green:** `#0066CC` or `#00A86B` (safety/trust)
- **Accent Orange/Red:** `#FF6B35` or `#E63946` (risk/urgency)
- **Neutral Grays:**
  - Dark text: `#1A1A1A` or `#2D2D2D`
  - Medium gray: `#6B6B6B`
  - Light gray: `#E5E5E5`
  - Background: `#FFFFFF` or `#FAFAFA`

### Typography Hierarchy
- **H1 (Slide Titles):** 48-60px, Bold, Primary color
- **H2 (Section Headers):** 32-40px, Semi-bold
- **H3 (Subsections):** 24-28px, Medium
- **Body Text:** 16-18px, Regular
- **Bullet Points:** 16px, Regular, Line height 1.6

### Layout Guidelines
- **Padding:** 40-60px from edges
- **Max content width:** 1200px (centered)
- **Grid:** Use 8px or 12px grid system
- **White space:** Generous spacing between elements

## Implementation Checklist

### Before Starting
- [ ] Set up master slide template with brand colors
- [ ] Create text styles (H1, H2, H3, Body)
- [ ] Prepare icon library or access to icons
- [ ] Set slide dimensions (16:9 recommended)

### During Build
- [ ] Create Slide 1 (Title) first as template
- [ ] Build Slides 2-4 (Foundation slides)
- [ ] Build Slides 5-9 (Theme slides - use consistent template)
- [ ] Build Slides 10-13 (Pillars and Timeline)
- [ ] Build Slides 14-19 (Strategy and Outcomes)
- [ ] Build Slide 20 (Closing)

### After Build
- [ ] Review all slides for consistency
- [ ] Check typography hierarchy
- [ ] Verify color usage
- [ ] Test readability at presentation distance
- [ ] Add transitions/animations if desired
- [ ] Export for review

## Notes for Figma Slides

1. **Use Components:** Create reusable components for:
   - Theme slide template
   - Timeline markers
   - Outcome cards
   - Pillar cards

2. **Master Slides:** Set up master slides for:
   - Title slide
   - Content slide (with header)
   - Section divider

3. **Text Styles:** Create text styles for:
   - H1 (Slide titles)
   - H2 (Section headers)
   - H3 (Subsections)
   - Body (Regular text)
   - Emphasis (Highlighted text)

4. **Color Styles:** Create color styles for:
   - Primary (Blue/Green)
   - Accent (Orange/Red)
   - Text Dark
   - Text Medium
   - Background

5. **Spacing:** Use consistent spacing:
   - 8px or 12px grid
   - 40-60px padding from edges
   - 24-32px between sections

# Opportunity: Customers Need Enterprise System Integrations

**Status:** Backlog  
**Created:** 2026-01-03  
**Last Updated:** 2026-01-03  
**Priority:** High

## Overview

Enterprise customers need integrations with HR, ERP, CMMS, and project controls systems. System integrations are mandatory for enterprise deals, and customers expect tight linkage with existing enterprise systems to enable unified data flows and reduce manual work.

## Customer Problem

Enterprise customers struggle with:
- Manual data entry and duplicate work across systems
- Lack of integration with existing enterprise systems (HR, ERP, CMMS, project controls)
- Inability to achieve unified data flows across safety, operations, and ESG
- Complex configuration and setup requirements for integrations
- Limited visibility into cross-system data and workflows

**What Customers Need:**
- HR/HRIS integrations for personnel data and training records
- ERP integrations for financial and operational data
- CMMS/EAM integrations for maintenance and equipment data
- Project controls integrations for project and schedule data
- Open API ecosystems for modular, event-driven architectures

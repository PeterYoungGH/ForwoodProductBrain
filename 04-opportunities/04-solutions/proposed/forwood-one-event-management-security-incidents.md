# Solution: Forwood One Event Management for Security Incidents

**Status:** Proposed  
**Created:** 2025-12-01  
**Last Updated:** 2025-12-01  
**Priority:** Medium

## Overview

Use Forwood One Event Management capabilities to enable Security incident management and investigations within the Forwood platform, allowing customers to extend their existing EHS platform investment to also support Security operations without implementing a separate system.

## Related Opportunity

Link to the opportunity this solution addresses:
- [Customers Want to Extend Existing Platform to Support Security Incident Management](../03-opportunities/active/kenmare-extend-platform-security-incident-management.md)

## Solution Description

Forwood One Event Management is a planned capability that will enable customers to manage various types of incidents and events within the unified Forwood One platform. This solution would leverage Event Management capabilities to support Security incident management and investigations, allowing customers to:

- Configure Security-related incident categories, workflows, and evidence tracking
- Use the same base data structure (sites, locations, departments, employees) already available for EHS
- Manage Security incidents as a separate module or area with appropriate access controls
- Develop Security-specific dashboards and heat maps similar to EHS dashboards
- Maintain data separation and permissions between EHS and Security teams while sharing base infrastructure

The solution would extend Forwood One's Event Management capabilities to specifically support Security incident management workflows, leveraging the platform's existing data model and infrastructure while providing domain-specific configurations and access controls.

**Key Components:**
- Security incident category configuration
- Security-specific workflows and processes
- Evidence tracking for Security investigations
- Access control and permission management for Security vs EHS teams
- Security-specific dashboards and reporting
- Heat maps and trend analysis for Security incidents

## How It Addresses the Opportunity

This solution directly addresses the customer opportunity by:

1. **Avoiding System Proliferation**: Customers can extend their existing Forwood platform rather than implementing a new Security incident management system
2. **Unified Data Model**: Leverages the same base data structure (sites, locations, departments, employees) for consistency across EHS and Security domains
3. **Operational Efficiency**: Eliminates the need to switch between systems and duplicate data entry
4. **Unified Reporting**: Enables Security-specific dashboards and heat maps while maintaining the ability to create unified views across domains
5. **Platform Value Maximization**: Allows customers to maximize value from their existing Forwood investment by extending it to additional use cases

By providing Security incident management capabilities within Forwood One Event Management, customers can consolidate their incident management operations into a single platform while maintaining appropriate separation and access controls between different operational domains.

## Assumptions

- Forwood One Event Management will be developed with sufficient flexibility to support Security incident management workflows
- Security incident management workflows are similar enough to EHS incident management that they can be supported by the same platform capabilities
- Customers are willing to have Security and EHS data in the same system (with appropriate access controls)
- Forwood One Event Management timeline aligns with customer needs
- Security incident management requirements don't differ significantly from EHS incident management in ways that would require major platform changes
- Access control and permission management capabilities will be sufficient to maintain appropriate separation between EHS and Security teams

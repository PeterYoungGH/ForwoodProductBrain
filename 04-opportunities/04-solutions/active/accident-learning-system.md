# Solution: Accident Learning System (ALS)

**Status:** Active  
**Created:** 2025-11-28  
**Last Updated:** 2025-12-17

## Overview

The Accident Learning System (ALS) is a patented system that updates checklists in real time after a fatality or serious incident. It automatically identifies missing or unclear questions and updates CRM checklists globally and instantly, ensuring that learnings from incidents are immediately incorporated into the system to prevent future occurrences.

## Solution Description

The Accident Learning System (ALS) is a patented real-time learning mechanism that:

1. **Monitors Incidents:** Tracks fatalities and serious incidents
2. **Investigates:** Reviews incident details and root causes
3. **Learns:** Identifies missing questions or unclear content in checklists
4. **Updates Globally:** Immediately updates relevant checklists across all deployments worldwide

**Key Features:**
- Real-time checklist updates after incidents
- Global propagation of learnings
- Automatic identification of missing safety questions
- Instant deployment to all CRM instances

**Example - Kinross Incident:**
A worker died in a fuel vapour explosion inside a shipping container. The ALS identified a missing gas-test question and updated the Hot Work checklist globally and instantly, ensuring all future Hot Work activities include the critical gas-test question.

## How It Addresses the Opportunity

The ALS addresses the critical need to learn from incidents and prevent future occurrences by:
- Ensuring that every fatality or serious incident results in immediate system improvements
- Eliminating the delay between incident occurrence and system updates
- Creating a continuous learning loop that improves safety over time
- Preventing the same type of incident from occurring elsewhere by sharing learnings globally

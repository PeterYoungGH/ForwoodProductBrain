## Description

The goals of this phase are:

* **Commercial:** Oculus is demonstratable to prospects (Sales calls, Internal Product and Marketing presentations)

    * Validate a pipeline of prospects able to be nurtured for this version
    
* **Usability and Feasability:** All base level required Saas functionality is linked up with the MVP resulting in a version of the product that it is possible to onboard a client into (albeit with some assistance from intermal Forwood roles - Taxonomy, content etc)
* **Value:** Provide the Product team with a viable feedback loop based on actual product usage and client feedback

# Journal

Daily journal entries for brain dumps, thoughts, and reflections.

## Purpose

This folder contains dated journal entries that can be referenced throughout the Product Brain system. Journal entries are:
- Dated and timestamped
- Available for reference in communications, research, and other documents
- Not automatically processed into the inbox workflow
- Available for linking and cross-referencing

## File Naming

Journal entries use the format: `YYYY-MM-DD.md`

Example: `2026-01-15.md`

## Usage

Use the command:
```
pm.add-journal-entry
```

This will:
1. Create a new journal entry file with today's date
2. Include date and time in the file header
3. Allow you to add your journal content

## Linking Journal Entries

Journal entries can be linked from:
- Communications documents
- Research documents
- Opportunity documents
- Solution documents
- Any other document in the system

Use relative paths: `[[08-journal/2026-01-15.md|Journal Entry - 2026-01-15]]`

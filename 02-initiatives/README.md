# Initiatives

Strategic initiatives and programs that drive product strategy.

## Purpose

This section tracks strategic initiatives - larger programs of work that span multiple opportunities and solutions. Each initiative should be clearly linked to strategic goals and outcomes.

## Structure

- `active/` - Currently active initiatives
- `planned/` - Initiatives planned but not yet started
- `archive/` - Completed initiatives

## Creating an Initiative

1. Use the template from `06-reference/templates/initiative-template.md`
2. Create a file in the appropriate folder: `active/`, `planned/`, or `archive/`
3. Link to related:
   - Strategic focus areas in `01-strategy/strategic-focus/`
   - Business outcomes in `04-opportunities/01-business-outcomes/`
   - Opportunities in `04-opportunities/03-opportunities/`

## Navigation

- Check `active/` for current work
- Review `planned/` for upcoming initiatives
- Browse `archive/` for historical context

## Best Practices

- Each initiative should have clear success metrics
- Link initiatives to supporting opportunities and solutions
- Update status regularly as initiatives progress
- Archive completed initiatives with outcomes documented

# pm.apply-decision-framework

**Step 5** - Command to apply decision frameworks (OST, risk assessment, etc.) to product strategy and development decisions.

## Command Purpose

This command applies decision frameworks to structure product work, assess risks, or make product decisions.

## Execution Steps

### Step 1: Read Required Files

1. **Determine Framework**
   - Identify which framework to apply (OST, risk assessment, etc.)
   - Read the appropriate prompt:
     - OST: `07-reference/prompts/decision-frameworks/ost-application-prompt.md`
     - Risk Assessment: `07-reference/prompts/decision-frameworks/risk-assessment-prompt.md`

2. **Read Framework Methodology**
   - Read the methodology document for the framework:
     - OST: `07-reference/methodology/opportunity-solution-tree-guide.md`
     - Risk Assessment: `07-reference/methodology/four-product-risks-framework.md`

3. **Read Context Documents**
   - Files: Paths to relevant documents (opportunities, solutions, outcomes, etc.)
   - Purpose: Context for applying the framework
   - Action: Read and understand the context

### Step 2: Apply Framework Prompt

1. **Apply the Prompt**
   - Use the appropriate framework prompt
   - Follow the framework structure:
     - OST: Map business outcomes to product outcomes, identify opportunities, structure solutions
     - Risk Assessment: Evaluate value, usability, feasibility, and business viability risks

2. **Structure Analysis**
   - Organize by framework structure
   - Document findings and recommendations
   - Link to related documents

### Step 3: Generate Analysis Document

1. **Create Document**
   - Generate structured analysis document
   - Include framework application results
   - Document findings and recommendations
   - Link to related documents

### Step 4: Save Document

1. **Determine Location**
   - Based on framework type and context
   - Use descriptive filename: `YYYY-MM-DD-[framework]-[topic].md`

2. **Save and Link**
   - Save the analysis document
   - Link from related documents (if applicable)
   - Update any index files if needed

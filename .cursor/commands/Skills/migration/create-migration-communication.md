# Create Migration Communication

**Category:** Migration
**Strategic Theme:** N/A
**Autonomy Level:** Full
**Workflow Stages:** All (Migration program)

## Purpose
Generate customer-facing updates and communications for migration projects.

## Inputs Required
- Migration stage and status
- Key milestones and dates
- Customer concerns
- Audience (exec, user, IT)

## Process Steps
1. **Identify communication need** - What needs to be said?
2. **Tailor to audience** - Exec vs user vs IT
3. **Lead with what matters** - Timeline, impact, actions
4. **Address concerns** - Acknowledge and resolve
5. **Include clear next steps** - What they need to do

## Output Format
Migration communication tailored to audience with key messages and actions.

# Assess Migration Readiness

**Category:** Migration
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** All (Migration program)

## Purpose
Evaluate customer readiness for migration to Forwood One platform.

## Inputs Required
- Customer profile and current state
- Technical requirements
- Organizational readiness
- Timeline constraints

## Process Steps
1. **Assess technical readiness** - Infrastructure, integrations, data
2. **Evaluate organizational readiness** - Change management, training
3. **Check data migration complexity** - Volume, quality, mappings
4. **Identify blockers** - What could prevent success?
5. **Score overall readiness** - Ready/Needs Work/Not Ready

## Output Format
Migration readiness assessment with scores, blockers, and recommendations.

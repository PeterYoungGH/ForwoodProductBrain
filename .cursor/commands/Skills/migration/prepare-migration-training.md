# Prepare Migration Training

**Category:** Migration
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** All (Migration program)

## Purpose
Create training materials and plans for customers migrating to Forwood One.

## Inputs Required
- Feature differences (old vs new)
- User personas
- Learning objectives
- Delivery constraints

## Process Steps
1. **Identify training needs** - What do users need to learn?
2. **Segment by audience** - Different needs for different users
3. **Create content** - Guides, videos, exercises
4. **Plan delivery** - When and how
5. **Measure effectiveness** - How to know it worked

## Output Format
Training plan with content outline, delivery schedule, and success metrics.

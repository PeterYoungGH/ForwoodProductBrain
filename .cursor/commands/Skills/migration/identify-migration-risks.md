# Identify Migration Risks

**Category:** Migration
**Strategic Theme:** N/A
**Autonomy Level:** Full
**Workflow Stages:** All (Migration program)

## Purpose
Find potential blockers and risks in customer migration projects.

## Inputs Required
- Customer context
- Technical environment
- Timeline constraints
- Historical migration data

## Process Steps
1. **Assess technical risks** - Integration, data, performance
2. **Evaluate people risks** - Training, adoption, resistance
3. **Check timeline risks** - Dependencies, constraints
4. **Identify external risks** - Customer capacity, decisions
5. **Rate and prioritize** - Impact and likelihood

## Output Format
Migration risk register with ratings, mitigations, and owners.

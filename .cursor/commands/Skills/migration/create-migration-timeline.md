# Create Migration Timeline

**Category:** Migration
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** All (Migration program)

## Purpose
Generate customer-specific migration schedules with milestones and dependencies.

## Inputs Required
- Customer readiness assessment
- Resource availability
- Dependencies and constraints
- Target go-live date

## Process Steps
1. **Define major milestones** - Key dates and deliverables
2. **Identify dependencies** - What must happen first
3. **Allocate resources** - Who when
4. **Build contingency** - Buffer for unknowns
5. **Create visual timeline** - Easy to communicate

## Output Format
Migration timeline with milestones, dependencies, resources, and visual representation.

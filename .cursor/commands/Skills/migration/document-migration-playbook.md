# Document Migration Playbook

**Category:** Migration
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** All (Migration program)

## Purpose
Structure migration processes into repeatable playbooks for consistent execution.

## Inputs Required
- Migration process steps
- Lessons learned
- Common issues and resolutions
- Stakeholder responsibilities

## Process Steps
1. **Document phases** - Pre, during, post migration
2. **Define checklists** - What must be done at each step
3. **Assign responsibilities** - Who does what
4. **Capture troubleshooting** - Common issues and fixes
5. **Include templates** - Reusable artifacts

## Output Format
Migration playbook with phases, checklists, responsibilities, and templates.

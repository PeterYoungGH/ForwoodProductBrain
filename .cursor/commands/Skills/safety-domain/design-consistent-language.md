# Design Consistent Language

**Category:** Safety Domain
**Strategic Theme:** Theme 5 (Standardization Without Rigidity)
**Autonomy Level:** Supervised
**Workflow Stages:** 5 (Solution Exploration)

## Purpose
Create shared terminology and language across sites to enable clear communication.

## Inputs Required
- Current terminology variations
- Industry standards
- User feedback on confusion
- Translation/localization needs

## Process Steps
1. **Audit current terms** - What words are used?
2. **Identify conflicts** - Where do meanings differ?
3. **Propose standard terms** - What should be official?
4. **Create glossary** - Definitions and usage
5. **Plan adoption** - How to roll out

## Output Format
Terminology design with glossary, mapping from old terms, and adoption plan.

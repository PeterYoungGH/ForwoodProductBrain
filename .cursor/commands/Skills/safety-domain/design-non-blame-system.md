# Design Non-Blame System

**Category:** Safety Domain
**Strategic Theme:** Theme 3 (Credibility & Trust Through Systems)
**Autonomy Level:** Supervised
**Workflow Stages:** 5 (Solution Exploration)

## Purpose
Design features that enable truth-telling and learning by removing blame from safety systems.

## Inputs Required
- Current system analysis
- Blame culture indicators
- Just culture framework
- VoC on trust issues

## Process Steps
1. **Identify blame triggers** - What creates fear?
2. **Design anonymous options** - Where appropriate
3. **Separate learning from discipline** - Clear boundaries
4. **Enable psychological safety** - How to make it safe
5. **Communicate intent** - How users know it's safe

## Output Format
Non-blame system design with features, communications, and safeguards.

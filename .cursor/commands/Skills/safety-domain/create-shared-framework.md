# Create Shared Framework

**Category:** Safety Domain
**Strategic Theme:** Theme 5 (Standardization Without Rigidity)
**Autonomy Level:** Supervised
**Workflow Stages:** 5, 7 (Solution Exploration, Roadmap Inclusion)

## Purpose
Design cross-site frameworks that enable consistency without stifling local adaptation.

## Inputs Required
- Current site variations
- Core requirements (non-negotiable)
- Local adaptation needs
- Change management context

## Process Steps
1. **Identify core requirements** - What must be consistent?
2. **Allow local variation** - Where can sites adapt?
3. **Create shared language** - Common terminology
4. **Enable comparison** - How to compare across sites
5. **Plan rollout** - How to implement

## Output Format
Framework design with core requirements, adaptation zones, and implementation plan.

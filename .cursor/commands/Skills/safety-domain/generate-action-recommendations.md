# Generate Action Recommendations

**Category:** Safety Domain
**Strategic Theme:** Theme 2 (From Data Collection to Action)
**Autonomy Level:** Full
**Workflow Stages:** 2, 5 (Insight Extraction, Solution Exploration)

## Purpose
Turn safety data into specific, actionable recommendations that drive improvement.

## Inputs Required
- Safety data and analysis
- Context and constraints
- Available resources
- Priority framework

## Process Steps
1. **Analyze data for patterns** - What needs attention?
2. **Prioritize by risk** - Highest SIF potential first
3. **Formulate specific actions** - Who does what by when
4. **Check feasibility** - Can this actually be done?
5. **Link to outcomes** - How will we know it worked?

## Output Format
Action recommendations with owners, deadlines, and success criteria.

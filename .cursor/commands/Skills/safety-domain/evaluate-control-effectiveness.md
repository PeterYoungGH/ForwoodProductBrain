# Evaluate Control Effectiveness

**Category:** Safety Domain
**Strategic Theme:** Theme 4 (Controls That Actually Work)
**Autonomy Level:** Supervised
**Workflow Stages:** 2, 4, 6 (Various)

## Purpose
Verify that safety controls actually prevent harm rather than just satisfying audits.

## Inputs Required
- Control inventory
- Implementation evidence
- Incident data
- Audit results

## Process Steps
1. **Verify implementation** - Is control actually in place?
2. **Test effectiveness** - Does it prevent the harm?
3. **Check worker experience** - Do workers follow it?
4. **Compare to incidents** - Did control fail?
5. **Rate effectiveness** - Effective/Partially/Ineffective

## Output Format
Control effectiveness evaluation with ratings and improvement recommendations.

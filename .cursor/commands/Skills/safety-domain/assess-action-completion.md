# Assess Action Completion

**Category:** Safety Domain
**Strategic Theme:** Theme 2 (From Data Collection to Action)
**Autonomy Level:** Full
**Workflow Stages:** 6 (Experimentation/Validation)

## Purpose
Track and evaluate completion of safety actions to ensure follow-through.

## Inputs Required
- Actions to track
- Completion criteria
- Timeline requirements
- Status data

## Process Steps
1. **Check completion status** - Is it done?
2. **Verify quality** - Was it done well?
3. **Assess timeliness** - Was it on time?
4. **Identify blockers** - What's preventing completion?
5. **Report on trends** - Improving or declining?

## Output Format
Action completion assessment with status, trends, and recommendations.

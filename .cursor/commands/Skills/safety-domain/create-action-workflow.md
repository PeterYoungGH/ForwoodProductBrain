# Create Action Workflow

**Category:** Safety Domain
**Strategic Theme:** Theme 2 (From Data Collection to Action)
**Autonomy Level:** Supervised
**Workflow Stages:** 5 (Solution Exploration)

## Purpose
Design workflows that ensure safety actions are completed and don't fall into the "black hole."

## Inputs Required
- Action types to workflow
- Stakeholder responsibilities
- Escalation requirements
- Integration points

## Process Steps
1. **Define action lifecycle** - From creation to completion
2. **Assign clear ownership** - Who is responsible?
3. **Set checkpoints** - When to check progress
4. **Design escalation** - What if overdue?
5. **Enable visibility** - Who sees status?

## Output Format
Action workflow design with lifecycle, ownership, and escalation paths.

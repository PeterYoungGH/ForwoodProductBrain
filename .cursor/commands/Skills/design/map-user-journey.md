# Map User Journey

**Category:** Design
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** 5 (Solution Exploration)

## Purpose
Create user journey maps that visualize the end-to-end experience for a specific user task or goal.

## Inputs Required
- User persona and context
- Task or goal to map
- Research on current experience
- Touchpoints and channels

## Process Steps
1. **Define the journey scope** - Start and end points
2. **Identify stages** - Major phases of the journey
3. **Map touchpoints** - Where user interacts with product
4. **Capture emotions** - How user feels at each stage
5. **Identify pain points** - Where friction occurs
6. **Find opportunities** - Where to improve

## Output Format
User journey map with stages, touchpoints, emotions, pain points, and opportunities.

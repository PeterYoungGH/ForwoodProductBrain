# Describe Wireframe

**Category:** Design
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** 5 (Solution Exploration)

## Purpose
Generate wireframe specifications that describe UI layouts and components for design implementation.

## Inputs Required
- Feature requirements
- User stories
- Design patterns to apply
- Constraints (mobile, desktop, etc.)

## Process Steps
1. **Define screen purpose** - What is user trying to do?
2. **Identify key components** - What elements are needed?
3. **Describe layout** - Where components are positioned
4. **Specify interactions** - What happens on click/tap
5. **Note responsive behavior** - How it adapts to screen sizes

## Output Format
Wireframe description with component list, layout, interactions, and responsive notes.

# Recommend UX Patterns

**Category:** Design
**Strategic Theme:** N/A
**Autonomy Level:** Full
**Workflow Stages:** 5 (Solution Exploration)

## Purpose
Suggest appropriate UX patterns based on user needs and design system standards.

## Inputs Required
- User task or problem
- Context and constraints
- Design system reference
- Platform (web, mobile, etc.)

## Process Steps
1. **Understand the user task** - What are they trying to accomplish?
2. **Review design system** - What patterns exist?
3. **Research industry patterns** - What do others use for this?
4. **Match pattern to need** - Which fits best?
5. **Document rationale** - Why this pattern?

## Output Format
Pattern recommendations with examples and rationale.

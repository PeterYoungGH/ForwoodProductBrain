# Design Information Architecture

**Category:** Design
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** 5 (Solution Exploration)

## Purpose
Structure content and navigation to make information findable and understandable.

## Inputs Required
- Content inventory
- User mental models
- Navigation requirements
- Search and filter needs

## Process Steps
1. **Audit existing content** - What exists today
2. **Understand user mental models** - How do they think about this?
3. **Create taxonomy** - Categories and labels
4. **Design hierarchy** - What contains what
5. **Plan navigation** - How users move through content

## Output Format
IA documentation with taxonomy, hierarchy, and navigation design.

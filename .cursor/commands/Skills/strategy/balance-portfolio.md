# Balance Portfolio

**Category:** Strategy
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** 7 (Roadmap Inclusion)

## Purpose
Assess portfolio balance and gaps across innovation types, themes, and time horizons.

## Inputs Required
- Current roadmap items with classifications
- Innovation scores for each item
- Strategic theme coverage
- Resource allocation

## Process Steps
1. **Map current portfolio** - Plot items by innovation type
2. **Check theme coverage** - Are all themes represented?
3. **Check time horizon balance** - Now/Next/Later distribution
4. **Identify gaps** - Where is coverage weak?
5. **Recommend rebalancing** - What to add, deprioritize, or adjust

## Output Format
Portfolio analysis with coverage gaps and rebalancing recommendations.

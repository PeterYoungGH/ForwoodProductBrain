# Align to Strategy

**Category:** Strategy
**Strategic Theme:** All Themes
**Autonomy Level:** Full
**Workflow Stages:** 4, 5, 7 (Opportunity Validation, Solution Exploration, Roadmap Inclusion)

## Purpose
Map work items to strategic pillars and themes, ensuring alignment with company direction.

## Inputs Required
- Item to align (opportunity, solution, initiative)
- Strategic themes (Themes 1-5)
- Strategic pillars (Ease of Use, SIF Prevention, Adoption, Data Insights)
- Current roadmap priorities

## Process Steps
1. **Review strategic themes** - Which themes does this support?
2. **Review strategic pillars** - Which pillars does this advance?
3. **Assess alignment strength** - Strong/Moderate/Weak/None
4. **Identify conflicts** - Does this contradict any strategy?
5. **Document rationale** - Why this alignment assessment

## Output Format
Alignment assessment with theme/pillar mapping and rationale.

# Sequence Initiatives

**Category:** Strategy
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** 7 (Roadmap Inclusion)

## Purpose
Determine optimal order for initiatives based on dependencies, strategic value, and resources.

## Inputs Required
- List of initiatives to sequence
- Dependencies between initiatives
- Resource constraints
- Strategic priorities

## Process Steps
1. **Map dependencies** - What must come before what?
2. **Identify parallel opportunities** - What can happen simultaneously?
3. **Apply strategic priority** - Higher priority items first
4. **Consider resource constraints** - What capacity allows
5. **Create sequence** - Ordered list with rationale

## Output Format
Sequenced initiative list with dependencies, timing, and rationale.

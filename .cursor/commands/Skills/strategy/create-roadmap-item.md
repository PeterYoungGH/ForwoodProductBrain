# Create Roadmap Item

**Category:** Strategy
**Strategic Theme:** N/A
**Autonomy Level:** Supervised
**Workflow Stages:** 7 (Roadmap Inclusion)

## Purpose
Structure validated solutions for inclusion in strategic, portfolio, or delivery roadmaps.

## Inputs Required
- Validated solution with experiment results
- Strategic alignment assessment
- Innovation score (if calculated)
- Resource requirements

## Process Steps
1. **Determine roadmap layer** - Strategic (6-12mo), Portfolio (3-6mo), or Delivery
2. **Define the item** - Name, description, outcomes, success metrics
3. **Assess dependencies** - What must come before/after
4. **Estimate resources** - Team, time, budget
5. **Suggest timeline** - Quarter or release window

## Output Format
Roadmap item with layer placement, dependencies, and success metrics.

# Prepare Presentation Outline

**Category:** Communication
**Strategic Theme:** N/A
**Autonomy Level:** Full
**Workflow Stages:** All

## Purpose
Structure presentations with clear narrative flow and key messages for various audiences.

## Inputs Required
- Presentation topic and goal
- Audience and context
- Key content and data
- Time allocation

## Process Steps
1. **Define objective** - What should audience think/do after?
2. **Structure narrative** - Beginning, middle, end
3. **Plan key slides** - 1 idea per slide
4. **Include data visualizations** - Where charts/graphs help
5. **End with call to action** - What do you want them to do?

## Output Format
Presentation outline with slide structure and key talking points.

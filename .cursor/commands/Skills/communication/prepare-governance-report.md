# Prepare Governance Report

**Category:** Communication
**Strategic Theme:** Theme 1 (Fatal Risk Visibility)
**Autonomy Level:** Supervised
**Workflow Stages:** All

## Purpose
Create board-level governance and oversight documents for regulatory or corporate governance needs.

## Inputs Required
- Governance requirements and framework
- Performance data and metrics
- Compliance status
- Key decisions and recommendations

## Process Steps
1. **Follow governance framework** - Required sections and format
2. **Report on KPIs** - Status against targets
3. **Highlight exceptions** - What requires board attention
4. **Document decisions** - Decisions made or needed
5. **Include forward look** - Upcoming items and risks

## Output Format
Formal governance report meeting board requirements.

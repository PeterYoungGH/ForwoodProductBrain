# Write Executive Summary

**Category:** Communication
**Strategic Theme:** N/A
**Autonomy Level:** Full
**Workflow Stages:** All

## Purpose
Create one-page executive summaries that communicate key information to leadership efficiently.

## Inputs Required
- Topic content to summarize
- Audience (C-suite, Board, leadership)
- Context and urgency level

## Process Steps
1. **Identify the key message** - What's the one thing they must know?
2. **Structure pyramid-style** - Conclusion first, then supporting points
3. **Include data points** - 2-3 key metrics or facts
4. **State the ask** - What decision or action is needed?
5. **Keep to one page** - Ruthlessly prioritize

## Output Format
One-page summary with headline, key points, data, and clear ask.

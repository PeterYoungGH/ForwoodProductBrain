# Generate Stakeholder Update

**Category:** Communication
**Strategic Theme:** N/A
**Autonomy Level:** Full
**Workflow Stages:** All

## Purpose
Create regular status updates for various stakeholder groups with appropriate detail level.

## Inputs Required
- Update period and scope
- Stakeholder audience
- Key progress, blockers, and next steps
- Relevant metrics

## Process Steps
1. **Identify audience needs** - What do they care about?
2. **Summarize progress** - What was accomplished
3. **Flag blockers** - What needs attention
4. **Share next steps** - What's coming
5. **Include metrics** - Quantifiable progress

## Output Format
Stakeholder update tailored to audience with progress, blockers, and next steps.

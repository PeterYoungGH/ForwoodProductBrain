# Write Release Notes

**Category:** Communication
**Strategic Theme:** N/A
**Autonomy Level:** Full
**Workflow Stages:** Post-delivery

## Purpose
Generate user-facing release notes that communicate new features, improvements, and fixes.

## Inputs Required
- Features and changes in release
- User impact of each change
- Known issues (if any)

## Process Steps
1. **Group by type** - New features, improvements, fixes
2. **Write user-centric descriptions** - Benefits, not technical details
3. **Prioritize by impact** - Most important first
4. **Include visuals** - Screenshots where helpful
5. **Note known issues** - Transparency about limitations

## Output Format
User-friendly release notes with categorized changes and benefits.

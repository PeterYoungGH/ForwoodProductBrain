# Synthesize Content

Command to synthesize information from multiple sources and create coherent narratives.

## Command Purpose

This command synthesizes information from multiple research sources, insights, or documents to create comprehensive views and identify patterns.

## Execution Steps

### Step 1: Read Required Files

1. **Read the Multi-Source Synthesis Prompt**
   - File: `07-reference/prompts/content-synthesis/multi-source-synthesis-prompt.md`
   - Purpose: Understand how to synthesize multiple sources
   - Action: Read and understand the prompt structure, parameters, and expected output

2. **Read Source Materials**
   - Files: Paths to multiple research documents, insights, or other sources
   - Purpose: Materials to synthesize
   - Action: Read and understand all source materials

3. **Read Related Documents (Optional)**
   - If synthesizing content that relates to existing documents, read those documents
   - Purpose: Understand context and identify relationships

### Step 2: Apply Multi-Source Synthesis Prompt

1. **Apply the Prompt**
   - Use the multi-source synthesis prompt to analyze all sources
   - Identify common themes and patterns
   - Resolve contradictions or conflicts
   - Create comprehensive understanding
   - Generate unified insights

2. **Structure Synthesis**
   - Organize by themes or patterns
   - Highlight areas of agreement
   - Note areas of contradiction and how to resolve them
   - Create coherent narrative

### Step 3: Apply Cross-Reference Prompt

1. **Read the Cross-Reference Prompt**
   - File: `07-reference/prompts/content-synthesis/cross-reference-prompt.md`
   - Purpose: Create cross-references between related documents
   - Action: Apply the prompt to create links

2. **Create Cross-References**
   - Identify related documents
   - Establish bidirectional links
   - Maintain traceability
   - Update index files if needed

### Step 4: Generate Synthesized Document

1. **Determine Document Type**
   - Research document: Use research document generation prompt
   - Insight document: Use insight document generation prompt
   - Other: Use appropriate document generation prompt

2. **Create Document**
   - Generate document following appropriate template
   - Include synthesized findings
   - Link to all source materials
   - Include cross-references

### Step 5: Save Document

1. **Determine Location**
   - Based on document type and content
   - Use descriptive filename: `YYYY-MM-DD-[topic]-synthesis.md`

2. **Save and Link**
   - Save the synthesized document
   - Link from source materials (if applicable)
   - Link to related opportunities or outcomes
   - Update any index files if needed

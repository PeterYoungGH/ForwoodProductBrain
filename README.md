# Product Strategy Knowledge Base

A markdown-based knowledge base for organizing product strategy, discovery, and stakeholder communication.

## Overview

This knowledge base helps organize and maintain:
- **Inbox**: Raw inputs and processing workflow for unorganized information
- **Strategic Focus**: High-level roadmaps, strategic focus areas, and product vision
- **Initiatives**: Strategic initiatives and programs
- **Discovery**: Research, experiments, and product discovery practices
- **Opportunity Solution Trees**: Business outcomes, product outcomes, opportunities, solutions, and experiments
- **Communications**: Stakeholder updates and presentations
- **Reference**: Templates and methodology documentation

## Quick Start

1. **Process Inbox**: Check `00-inbox/raw/` for new inputs that need processing
2. **Start with Strategy**: Review `01-strategy/` for current roadmap and strategic focus
3. **Explore Initiatives**: Check `02-initiatives/active/` for current work
4. **Review Discovery**: See `03-discovery/` for research and insights
5. **Navigate OST**: Use `04-opportunities/` to explore the Opportunity Solution Tree framework
6. **Generate Communications**: Use templates in `05-communications/templates/` for stakeholder updates

## Structure

```
00-inbox/            # Inbox for raw inputs and processing workflow
01-strategy/          # Strategic focus and roadmaps
02-initiatives/       # Strategic initiatives and programs
03-discovery/         # Research and product discovery
04-opportunities/     # Opportunity Solution Trees (OST framework)
05-communications/    # Stakeholder communications
06-reference/         # Templates and methodology
```

## Navigation

Each major section contains a README.md file with:
- Purpose and overview
- Navigation guide
- Links to key documents
- Best practices for that section

## File Naming Conventions

- Use **kebab-case** for all filenames (e.g., `user-onboarding-flow.md`)
- Include dates in **YYYY-MM-DD** format when time-sensitive (e.g., `2024-Q1-roadmap.md`)
- Use **descriptive names** that indicate content (e.g., `mobile-app-redesign.md` not `project-1.md`)

## Linking Strategy

Documents cross-reference using markdown links:
- Archived inbox items link to processed documents
- Processed documents link back to source inbox items
- Opportunities link to related solutions
- Initiatives link to supporting opportunities
- Research links to opportunities it informs
- Solutions link back to opportunities they address
- Business outcomes link to product outcomes
- Product outcomes link to opportunities

## Getting Started

1. Review the README in each section to understand its purpose
2. Use templates in `06-reference/templates/` when creating new documents
3. Follow the Opportunity Solution Tree methodology in `06-reference/methodology/`
4. Keep documents updated and linked to maintain traceability

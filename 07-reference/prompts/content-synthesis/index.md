# Content Synthesis Prompts

Prompts for synthesizing information across multiple sources and creating coherent narratives.

## Purpose

These prompts guide the synthesis of information from multiple sources, creating comprehensive views and identifying patterns across documents.

## Available Prompts

### Multi-Source Synthesis Prompt
**File**: `multi-source-synthesis-prompt.md`
**Use When**: Synthesizing information from multiple research sources, insights, or documents
**Related Commands**: `synthesize-content`, `synthesize-research`

Synthesizes multiple sources to:
- Identify common themes and patterns
- Resolve contradictions or conflicts
- Create comprehensive understanding
- Generate unified insights

### Cross-Reference Prompt
**File**: `cross-reference-prompt.md`
**Use When**: Creating cross-references and links between related documents
**Related Commands**: `synthesize-content`

Creates cross-references by:
- Identifying related documents
- Establishing bidirectional links
- Maintaining traceability
- Updating index files

## Usage Pattern

1. Identify multiple sources to synthesize
2. Read all relevant source documents
3. Apply multi-source synthesis prompt
4. Generate synthesized document
5. Apply cross-reference prompt to create links

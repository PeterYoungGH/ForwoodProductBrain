# Roadmap Inclusion Checklist

**Purpose:** Verify a solution or initiative is ready for roadmap inclusion, ensuring it meets strategic criteria and has proper validation.

## Pre-Inclusion Validation

Before assessing roadmap readiness, verify the item meets basic requirements:

### Solution/Initiative Quality
- [ ] Solution has been validated through experiments (or initiative is well-defined)
- [ ] Go/no-go decision has been made (for solutions)
- [ ] Decision to proceed has been logged
- [ ] All required documentation is complete

### Strategic Alignment
- [ ] Aligns with strategic roadmap themes
- [ ] Supports business outcomes
- [ ] Supports product outcomes
- [ ] Fits portfolio balance (moonshots vs small bets)

## Roadmap Readiness Criteria

An item is ready for roadmap inclusion when:

### 1. Validation Complete (for Solutions)
- [ ] Solution has been validated through experiments
- [ ] Go/no-go decision made (Proceed)
- [ ] Results support proceeding
- [ ] Decision logged with rationale

### 2. Innovation Scoring (for Innovation Items)
- [ ] Innovation score calculated using Innovation Decision Framework
- [ ] Revenue Potential scored (1-5)
- [ ] Reach & Impact scored (1-5)
- [ ] Buy-In & Feasibility scored (1-5)
- [ ] Execution Difficulty scored (1-5)
- [ ] Supporting factors considered

### 3. Strategic Alignment
- [ ] Aligns with roadmap themes
- [ ] Supports strategic pillars (Ease of Use, SIF Prevention, Adoption & Engagement, Data & Insights)
- [ ] Fits portfolio structure
- [ ] Timing is appropriate

### 4. Resource Considerations
- [ ] Resource requirements assessed
- [ ] Resource availability confirmed
- [ ] Dependencies identified
- [ ] Timeline is realistic

### 5. Initiative Definition (if creating initiative)
- [ ] Initiative scope is clear
- [ ] Success metrics defined
- [ ] Timeline established
- [ ] Ownership assigned

## Innovation Scoring Validation

### Revenue Potential
- [ ] Scored: [1-5]
- [ ] Evidence reviewed
- [ ] Rationale documented

### Reach & Impact
- [ ] Scored: [1-5]
- [ ] Evidence reviewed
- [ ] Rationale documented

### Buy-In & Feasibility
- [ ] Scored: [1-5]
- [ ] Evidence reviewed
- [ ] Rationale documented

### Execution Difficulty
- [ ] Scored: [1-5] (inverse - lower is better)
- [ ] Evidence reviewed
- [ ] Rationale documented

### Supporting Factors
- [ ] Differentiation advantage assessed
- [ ] Time-to-learn considered
- [ ] Regulatory/ESG alignment checked
- [ ] Strategic brand impact evaluated
- [ ] Customer pull vs push assessed

## Roadmap Placement

### Suggested Layer
- [ ] Strategic Roadmap (6-12 months)
- [ ] Portfolio Roadmap (3-6 months)
- [ ] Delivery Roadmap (weekly releases)

### Suggested Timeline
- [ ] Quarter: [Q1/Q2/Q3/Q4]
- [ ] Month: [Month]
- [ ] Rationale: [Why this timing]

## Inclusion Assessment

**Ready for Roadmap:**
- [ ] All pre-inclusion validation passed
- [ ] All readiness criteria met
- [ ] Strategic alignment confirmed
- [ ] Resource availability confirmed
- [ ] Roadmap placement determined

**Not Ready - Issues:**
- [ ] List blocking issues
- [ ] Identify what needs to be completed
- [ ] Suggest next steps

## Decision Logging

When roadmap inclusion is decided:
- [ ] Decision log entry created (HIGH RISK - requires full log)
- [ ] Initiative creation logged (if applicable)
- [ ] Roadmap placement logged
- [ ] Portfolio prioritization logged

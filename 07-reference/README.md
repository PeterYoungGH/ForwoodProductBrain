# Reference

Templates, methodology, and best practices.

## Purpose

This section contains reusable templates and methodology documentation to ensure consistency across the knowledge base.

## Structure

- `templates/` - Document templates
  - `initiative-template.md` - Template for initiatives
  - `opportunity-template.md` - Template for opportunities
  - `solution-template.md` - Template for solutions
  - `research-template.md` - Template for research documents
- `methodology/` - Process documentation
  - `opportunity-solution-tree-guide.md` - OST framework guide
  - `discovery-process.md` - Product discovery methodology
  - `product-delight-checklist.md` - Framework for evaluating product features for delight
  - `four-product-risks-framework.md` - Marty Cagan's framework for evaluating idea viability
  - `jobs-to-be-done-framework.md` - Framework for understanding customer progress and jobs
  - `navigating-uncertainty-risk-management-guide.md` - Best practices for risk management in high-risk industries
  - `critical-control-verification-preparation.md` - Guide to preparing for critical control verifications
  - `forwood-one-migration-experience-framework.md` - Framework for delivering world-class customer migrations to Forwood One
- `prompts/` - Reusable prompts library
  - `inbox-processing/` - Prompts for inbox workflow (analysis, integration, archiving)
  - `research-analysis/` - Prompts for research synthesis, insight extraction, market analysis
  - `opportunity-identification/` - Prompts for identifying and structuring opportunities
  - `document-generation/` - Prompts for creating structured documents
  - `content-synthesis/` - Prompts for synthesizing information across multiple sources
  - `decision-frameworks/` - Prompts for applying decision frameworks (OST, risk assessment, etc.)

## Using Templates

1. Copy the template for the document type you're creating
2. Fill in the relevant sections
3. Remove sections that don't apply
4. Add any additional sections needed
5. Save in the appropriate location based on document type

## Navigation

- Browse `templates/` when creating new documents
- Review `methodology/` to understand processes and frameworks
- Use `prompts/` to find reusable prompts for commands and agent behavior

## Best Practices

- Use templates as starting points, customize as needed
- Update templates based on learnings and feedback
- Keep methodology documentation current
- Link to methodology docs from relevant sections
- Use prompts from the prompts library to ensure consistent behavior
- Reference prompts in commands to maintain consistency across workflows
